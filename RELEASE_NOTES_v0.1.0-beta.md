# v0.1.0-beta

First public beta of **ChatGPT Desktop RTL Runtime**.

Highlights:
- no `app.asar` modification
- no Administrator requirement
- no certificate installation
- smart RTL + mixed Persian/English handling
- Vazirmatn for Persian/Arabic glyphs
- runtime-only and reversible

Tested initially on Windows 11 / OpenAI.Codex 26.924.6891.0.

Because ChatGPT Desktop's internal DOM can change, please report regressions
with the app package version and a screenshot that contains no private data.
